## What is this?

This is an assignment for Mrs. Davenport-Ghent's CS3 class to practice with linked list variations. Even if you're not in my class, you're welcome to try it!

## How does this work?

You will add code to complete the methods in the 4 linked list variation classes. Node and other common features are defined in ParentLL.java.
Tests are located in Main.java. You can uncomment the calls for each data structure object in order to test your work.
